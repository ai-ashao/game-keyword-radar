# V1.1 历史扫描与变化对比

状态：已完成
完成日期：2026-08-23

## 目标

在不引入数据库、账号或 SERP 自动化的前提下，让用户用本地已保存的扫描快照回答两个问题：上次扫描之后有哪些游戏信号变化，以及哪些页面机会值得重新检查。

## 范围

- 列出并回看 `data/processed` 中的历史快照；
- 任意选择观察快照和对比基线；
- 对比游戏新增、离场、玩家数、Steam 排名和游戏信号；
- 对比关键词机会新增、移除和研究优先级升降；
- 从选中快照下载对应的 Markdown 报告；
- 兼容可推导 `raw_score` 的早期本地快照。

## 明确不做

- 不录入或自动抓取 SERP；
- 不把快照变化解释成搜索量或搜索需求趋势；
- 不改变机会评分公式、69 分上限或 `needs_validation` 状态；
- 不加入数据库、登录、云同步、定时任务或 Twitch。

## 验收证据

- 历史索引、读取和路径安全有自动化测试；
- 可比性、游戏变化和机会变化有自动化测试；
- 历史、对比和选中快照报告接口有自动化测试；
- Dashboard 已在桌面和 390 × 844 窄屏中验证，无横向溢出；
- 两次真实 Steam 快照可完成切换和对比。
